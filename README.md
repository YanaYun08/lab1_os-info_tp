# Лабораторная работа 1: Сбор информации об ОС

Скрипт для сбора информации об операционной системе.

## Описание

Программа определяет ОС, собирает системные параметры и сохраняет их в JSON-файл. Работает на Windows, Linux.

## Используемые модули

- platform - информация об ОС
- os - системные операции
- socket - сетевые данные
- getpass - имя пользователя
- sys - информация о Python
- json - запись в JSON
- datetime - время сбора

## Собираемые параметры

**ОС:**
- название
- релиз
- версия
- архитектура машины
- битность
- процессор

**Python:**
- версия
- реализация
- путь к файлу

**Пользователь:**
- имя
- домашняя директория
- текущая директория

**Сеть:**
- hostname
- IP-адрес

**Система:**
- количество ядер CPU
- разделитель путей
- разделитель строк
- время сбора данных
